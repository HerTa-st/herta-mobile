# 油猴脚本：把 DeepSeek 的对话捞出来

## 为什么在电脑上做

DeepSeek 官方**没有导出功能**。能拿到的只有浏览器里那份登录态，所以采集端必须在这里，
手机只负责接收与归档。

## 装

1. 装 Tampermonkey（油猴）。
2. 新建脚本，把 `herta-export.user.js` 整个粘进去，保存。
3. **刷新** `https://chat.deepseek.com`（脚本只在页面加载时注入，装完不刷新是看不到的）。
4. 右下角会出现一块「Herta 对话导出器」；如果没出现，找右下角那个圆形的 **「导」** 按钮，
   或者按 **Alt + H**。面板可以收起（右上 ×），收起后从「导」按钮再打开。

## 只想要一个对话

1. 在左边点开那条对话（地址栏变成 `/a/chat/s/<id>`）
2. 面板上点 **「只收当前这个」** —— 其它已收集的会被丢掉，之后也只认这一个
3. 往上滚到顶，把历史加载完（老消息是懒加载的，不滚就没有）
4. 「导出 JSON 文件」

想恢复全收，点 **「改成全收」**。

## 用

两种方式，可以混着用：

- **被动收集**（推荐先这么干）：正常翻你的对话，脚本挂在 fetch/XHR 上顺手把站点自己
  请求回来的 JSON 抄一份。翻几个就攒几个。
- **自动翻一遍**：点一下，脚本按侧栏链接逐个点开、等历史加载、再下一个。慢，但不用你动手。
  中途可以「停止」。

攒够了点「导出 JSON 文件」，把文件发到手机（微信文件传输助手就够），在手机的
「导入 DeepSeek 对话」里选那个文件。

## 常见情况

| 看到什么 | 说明 |
|---|---|
| 右下角什么都没有 | 没刷新页面；刷新后还不行就看 Tampermonkey 图标上有没有数字角标（那是错误数） |
| 面板在，但一直「已收集 0 个对话」 | 你还没点开过任何对话；点两个，或者按「自动翻一遍」 |
| 「自动翻一遍」翻到一半不动了 | 侧栏是虚拟列表，滚下去才会加载更多；先把侧栏往下拉一拉再点 |
| 导出 0 个对话 | 脚本没认出来（可能站点改了数据结构），把面板上的日志发我 |

## 为什么不用接口直连

`/api/v0/...` 是非公开契约，请求体和签名随时会变。这个脚本**不猜请求**，只截获站点
自己的响应——接口改了名、加了字段，它照样能工作。

反过来，如果哪天 DeepSeek 改成 SSR 直接吐 HTML、不再用 JSON 拉历史，脚本会**明确告诉你
"没抓到"**，而不是导出一份空文件假装成功。

## 已知边界

- 只认 `role` + `content` 这种形状的消息；如果站点换了嵌套方式，需要改 `asMessages`。
- 会话列表靠 `a[href*="/chat/s/"]` 认；侧栏没展开时数量会偏少。
- 导出的 `id` 用站点侧的会话 id，重复导入不会在手机里长出两份。
- 不做图片：手机端的导入模型暂时只有文本。
