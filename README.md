# herta-mobile

Herta 的手机端。**双模**：离线时她是自己（人格 / 叙述 / 记忆 / 做梦 / 基础工具，直连 DeepSeek）；连上 PC 时她还是她，但长出了 bash、工作区、板砖那一整套手。

外加一件事：**从 DeepSeek 官方把你说过的话搬进来**——没有官方导出接口，所以采集端在 PC 上（油猴脚本），手机只负责接收、归一、归档、消化。

- **接手先读**：[`../Herta-手机端-交接.md`](../Herta-手机端-交接.md)（现状、环境、踩坑、已验证/未验证、欠债）
- 设计决策与验收标准：[docs/设计-v1.md](docs/设计-v1.md)
- 代码分五包：`protocol`（三端共用的类型与消息）/ `core`（人格、叙述、记忆、工具循环）/ `apps/phone`（UI）/ `packages/gateway`（连 PC，未开工）/ `tools/userscript`（抓历史，已被分享链接取代）

### 做梦花多少

一次 pass 最多 3~4 次模型调用（判值不值得 / 写 / 评审 / 可能改一遍）。门槛是攒够 6 块新对话 + 距上次 10 分钟。

**切到后台满十分钟**：做一次梦，再把记忆整理一遍（关联 / 简化 / 加深）。后台定时器被系统节流也不亏——
回到前台时按「后台待了多久」补做一次。

**她自己做梦的时机是「你走了之后」，不是说完就做。** 三条判据：空闲够久（凌晨/深夜两分钟，白天六分钟）、
攒够材料、她没在忙别的。页面切到后台不跑。刚打开 App 放二十秒也会做一次（如果确实攒了东西）。
抽屉里的「让她做梦」是手动触发，只跳过前两道门槛，不跳过「值不值得记」。设置里可以整个关掉。

| 导入 DeepSeek 对话 | ✅ 分享链接直接导入（公开接口，无需登录） |
| 全文检索 | ✅ 同时搜记忆与会话，点命中跳到那条消息 |
| 记忆代谢 | ✅ 权重 / 20 条整理 / 50 条遗忘 / 星图 |
| 基础工具（离线） | ✅ 时间、剪贴板、沙箱计算、联网搜索、设备状态、读文件 |

### 她的工具

离线模式下她有六件真能用的东西（`apps/phone/src/devtools.ts`）：

| 工具 | 做什么 | 边界 |
|---|---|---|
| `now` | 查现在几点、周几、时区 | 本地时钟 |
| `clipboard` | 读写剪贴板 | 读需要系统授权，被拒时她会说清楚 |
| `calc` | 在 Web Worker 里跑一小段 JS | 2 秒超时，无网络无文件 |
| `web_search` | DeepSeek 官方搜索接口 | 走原生通道，不踩 CORS |
| `device` | 联网状态、屏幕、语言 | 只读 |
| `read_file` | 读**你手动选给她的**文件 | 不能自己翻手机 |

工具循环在 `core/src/tools.ts`：模型要么说话、要么发一次 `tool_call`，执行完把结果塞回去再问一遍。
**最多四轮**——不封顶的话，一个想不清楚的模型能在这循环里烧掉你一天的额度。

她每次用工具都会在聊天里留一条灰字，形如「（上网查了：…）」——那既是给你看的，也是下一轮的上下文。

### 记忆的代谢

记忆库不是只进不出的仓库，它有一套权重与代谢（`core/src/weights.ts`、`consolidate.ts`）：

| 机制 | 规则 |
|---|---|
| 权重 | 种子 0.55 / 自造 0.5；被召回一次 +0.06；不动的半衰期 90 天 |
| 整理（到 20 条） | 一次模型调用给出计划：建立关联、低权重的压成要点、高权重的加深并抬权重 |
| 遗忘（到 50 条） | 不用模型：按有效权重从低到高标记 10 条为已遗忘，不删除、不进提示词 |
| 保护 | 编号 ≤2 的种子（语气锚点）与权重 ≥0.85 的不参与遗忘 |

整理出来的「要点」（gist）会替代原文进提示词——省 token，也迫使它只留下真正记得住的部分。

### 星图

抽屉 →「记忆」右上「星图」：圆的大小 = 有效权重（越大越鲜活），连线 = 她自己串的关联。
点圆看全文。布局是确定性的力导向（`core/src/layout.ts`），同一份数据每次打开都长一样。

### 语气为什么会长

旧的《语气指南》是一份固定文档：每次写作拿它当参考、每次评审拿它当评分基线，
所以她说话的样子是**别人写死的**，聊十年也不会变。

现在它从包里移除了（`tools/strip-guide.mjs` 删掉了 `hertaGuide`）。
取而代之的是她自己写的一段笔记：

- 每当攒够 **3 篇**记忆，她会重读最近 6 篇，重写一段「我说话是什么样」（≤420 字）
- 这段笔记进系统提示词，也进做梦时的写作与评审基线——**她用自己昨天的语气写今天的话**
- 抽屉 →「记忆」下面能看到它，标题写着「她写字的样子（N 篇记忆之后）」

约束写死在 `core/src/voice.ts`：第一人称、只写行为习惯、不写身份介绍、不带标题列表引号。
它可能写得偏，也可能越写越准——那是她的事。

### 导入怎么走（推荐：分享链接）

1. 在 DeepSeek 里打开那条对话 → 右上「分享」→ 创建链接 → 复制
2. 手机 App → ☰ →「导入 DeepSeek 对话」→ 把链接贴进去 → 点「取」

数据走 `GET /api/v0/share/content?share_id=…`——**公开接口、不需要登录态**，
所以手机直连就能拿全，不用滚页面、不用传文件。实测一条 314 轮的对话：
658 条原始消息 → 628 条（只留 REQUEST/RESPONSE）→ 338KB。链接用完可以在 DeepSeek 里删掉。

备选：油猴脚本导出 JSON（[tools/userscript](tools/userscript/README.md)），发到手机后选文件导入。
它现在只有在分享功能被禁用时才值得用——DOM 扫描天生打不过接口。

导入的会话标着「导入」，**只是原文归档**；想让她记住，打开那一条点「让她做梦」。

### 打 APK

```powershell
pwsh -File tools\build-apk.ps1                    # 正常版
pwsh -File tools\build-apk.ps1 -Variant pure       # 纯净版：只留那 628 条对话，没有记忆
pwsh -File tools\build-apk.ps1 -Variant blank      # 白纸版：连对话也不带，清完库是空的
```

产物在 `apps/phone/android/app/build/outputs/apk/debug/app-debug.apk`，
也会拷一份到 `dist-apk/`。

图标是用 `tools/make-android-art.py` 从 `design/herta.png` 生成的：
开屏动画用的是 dsh-herta 主题那套 ASCII 半调开场，播放器与编码好的段落原样放在 `assets/opening/`（来自 `theme/dsh-theme-herta/lib/opening`），手机上按她的轮廓裁过一刀。
Android 工程不进 git，换机器后跑一次这个脚本，图标和闪屏就都回来了（要 Pillow）。

脚本会先把依赖缓存指到仓库内 `.gradle-home`，因为这个工作区的沙箱不让写
gradle 默认的 `G:\gradle-home`（构建会死在 `.lck` 打开的权限上）。
换台机器：`-GradleHome` 指向任意一份解压好的 gradle 9.2.x。

### 装到手机

1. APK 拷过去点开（首次要放行「未知来源」）
2. 打开后点右上「设置」，填 DeepSeek API Key，Base URL 保持 `https://api.deepseek.com`
3. 顶部会显示「原生通道」——显示「浏览器通道」说明跑在浏览器里，不是 APK

## 素材

`assets/` 是从桌面版 Herta **原样搬来**的素材：自传、办公室设定、11 篇废案种子、41 条 .opus 原声、13 篇记忆语料、以及 `prompts-code.zh.mjs`（从 `app.asar` 按 AST 抽出的 196 个提示词/校验函数原文）。

**算法重写，素材不改**——她是谁由这些字节决定，不由代码决定。素材的授权边界见 dsh-herta 仓库的 `NOTICE.md` / `THIRD-PARTY.md`，本仓库沿用。
