dsh-herta / DSH Plugin

把 Herta 装进
DeepSeek Harness

她的人格、记忆、声音、界面——四层都装进你的 DSH。一条命令，或者在市场里搜 herta。

$dsh plugin --profile desktop add dsh-herta

装完要关窗重开——bundle 是启动期挂载的。独立安装用 --profile web。

四层，各自独立可验

不是「换了个 prompt」。四层分开做、分开能验证。

层内容落在哪
A 身份HertaBio 逐字作人格前缀，外加重写的处境与纪律agent preset
B 记忆记忆货架作动态提示词段；记忆与做梦的工具preset 行
C 语音80 条她本人的语音（开场白 / 语气词 / 自我收回 / 彩蛋）静态路由 + client
D 界面用她的组件渲染 DSH 会话；配色与 ASCII 开场来自主题包conversation.view

装之前先看兼容

面向 DSH 0.1.7-rc.1 ~ 0.3.0（0.2.1-rc.2 实测）。DSH 的 agent preset、设置域、会话格式在 0.1.5→0.1.7 之间都是破坏性变更，低版本装不上是正常的。

装它的另外两条路

插件市场

已收录进上游精选目录（PR #5946）。DSH 里搜 herta 就能一键装。

npm

包名 dsh-herta。目录里那个 install 字段是模板生成的，桌面应用要换成 desktop。

本地目录

开发者用 file: 装本仓库；桌面应用走内置的 plugin_manager。
