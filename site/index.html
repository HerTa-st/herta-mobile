她不只是会回话

左轨上是四个地方——对话、记忆、市场、播报。下面一个一个说。

记得住

ep / sem / note 三层记忆 + 带权联想图。会衰减、会合并，也会被重新想起。

睡一觉

零成本浅睡做衰减去重；有空时深睡六个阶段把对话熬成记忆，还会重写「我说话的样子」。

主动找你

按自己的行踪与时机开口，一天最多两次，夜里不吵。

四个模块

四张界面：对话、记忆网络、黑塔币、播报。

01 / CONVERSATION

对话 · 想与说是两件事

她说的话在你的屏幕上只占两种形态

「想」是页边批注，默认收成一行，点开才读；「说」才是正文。

聊天流里只有两种东西：你说的话、她说过的话。工具调用和过程全都不占正文，只在设置里留记录。

  • 每句话下面一枚用量徽章，点开看这一轮花了多少、花在哪
  • 长按消息可以复制、引用、单独重生成
  • 她换头像之后，历史消息里的头像也跟着换
02 / MEMORY

记忆 · NMS

三层记忆，一张会衰减的网

记忆分 ep 情景 / sem 语义 / note 语气 三层，互相之间连成带权的联想图。用得多的会变重，放着不动的会衰减。

网络图铺满整屏，按层筛选；点一个节点，从底部浮起卡片读那一条——图不会消失，所以你还看得见它跟谁连着。

  • 浅睡零成本：本地衰减、同标题去重、剪掉弱边
  • 深睡六个阶段把待处理的对话熬成记忆（有网、有空、你不在的时候）
  • 「我说话的样子」是她自己写的，你只能看
03 / MARKET

黑塔币 · 信用点

一个小市场，会亏，也会欠

HTC / 信用点，工作日开盘。行情是程序生成的虚构内容，别当真。

能做多也能做空，开仓上限是净资产的 3 倍。余额可以是负的——这里没有强平，但会被市场慢慢吃掉。

  • 快讯挂在 K 线上：每条都对得上某一根分钟 K，点开就知道那根为什么放量
  • 没有强平；爆了是你自己点「重开」，重开会留一条破产记录
  • 排行榜有净资产榜，也有一张欠款榜
04 / BROADCAST

星际和平播报

一天一期，她自己写的评

每天一期，真新闻、能点回原文。每条后面跟一句她的判断或吐槽——不是摘要。

搜不到就明说，宁可少发。她不编新闻；偶尔出现的彩蛋会标清楚那是编的。

  • 期号、历史期都在，往期可以翻
  • 关注标签由你维护，她只建议不自动改
  • 提醒时间到了会推一条，点进去就是当天那期

全服行情

真实接口，30 秒刷新。只读行情，不包含个人交易记录；接口不通时这段不出现。
