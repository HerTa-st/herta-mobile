Noto Sans SC (Variable)
Source: https://github.com/notofonts/noto-cjk
File: NotoSansSC-VF.ttf (Sans/Variable/TTF/Subset)
License: SIL Open Font License 1.1
Used as the app's fixed UI font ("Herta Sans") so Chinese text does not follow
the phone's system theme font (which may be a handwriting font).

The font file is bundled for offline use; do not replace it with a system font
stack in component CSS. Use var(--app-font).
