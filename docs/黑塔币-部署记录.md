## 二、FC 配置

- 产品：阿里云函数计算 FC 3.0（地域：cn-hangzhou）
- 函数：`coin-api`，运行环境 Node.js 20，入口 `index.handler`
- 触发器：HTTP 触发器，请求方法仅 **GET**，认证方式「无需认证」
- 代码目录：`fc/coin-api/`（`index.js` / `coin-core.js` / `news-pool.js` / `package.json`）
- 部署包：`herta-mobile/coin-api-deploy.zip`
- 接口行为：
  - `GET /api/daily` → `{version, serverTime, market}`，`Cache-Control: no-store`，`Access-Control-Allow-Origin: *`
  - 其它路径 → 404 JSON；POST 等方法 → 403（触发器只允许 GET，属正常）


## 五、注意事项

- FC 默认域名跟函数绑定，**删除/重建函数后地址可能变**，变了要同步改 App 设置并重打 APK。
- 网页目前只有 HTTP；要给 `www` 配 HTTPS 需申请证书并上传到 OSS 自定义域名（待办）。
- 部署用的 RAM 子账号 `deploy-bot` 用完建议删除或禁用 AccessKey。
- 算法同源：FC 的 `coin-core.js` 以 `phantom-market/app.js` 为准，改算法要同步跑 `node fc/coin-api/test/fc.test.mjs`。
