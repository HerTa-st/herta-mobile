# 开工手册 · 手机端流程重设计（16 批 · B1–B16 已全部落地）

> 怎么用：**每天开一个新窗口，粘那一批的「开工提示」**。做完能打包装机就算收工，第二天再开下一批。
> 预算：一天约 ¥10 的开工额度 ≈ 3–6 次会话，正好够一批。

---

## 0. 每天怎么开一个窗口

1. 新窗口第一句，粘这一批的「开工提示」（每批末尾那一段）。
2. 它应该先读三个地方，不读就别让它动手：
   - [设计-手机端流程重设计-2026-11.md](设计-手机端流程重设计-2026-11.md) 里对应的那一节
   - [CONTEXT.md](../CONTEXT.md)（词别用错：未接通 / 当前的脸 / 就地 / 她找过我 / 骨架 / 主题 / 锚点 / 槽位）
   - 这一批要改的文件本身
3. 收工前跑完三件事，缺一件不算做完：

        npm run typecheck
        npm test
        pwsh -File tools\build-apk.ps1

4. 出包之后**装到手机上点一遍**验收清单。清单没过就不算完，别把问题带到下一批。

### 三条跨批的规矩

- **一批只碰它自己列出的文件。** 想改别的，先停，在窗口里说清楚，别顺手改。
- **assets/ 与 runtime/ 不动。** 前者是她的素材，后者是桌面版原文；改它们等于换掉「她是谁」。
- **每批都要能往回退。** 我们改图标那天就吃过教训：apps/phone/android/ 不进 git，动它之前先备份到 tools/ 下。

## 2. 每批详情

### B1 · 首次流程

**目标**：陌生人装完 → 看得到「她还没接上」→ 填对 Key → 听到第一句话。全链路不断。

**先读**：设计文档 §4。代码位置：App.tsx（引导判定在挂载 effect 里、开屏在渲染树顶部）、components/Onboarding.tsx、components/Splash.tsx、hooks/useChatTurn.ts（没 Key 那条分支）、components/BroadcastView.tsx（空态）。

**改哪**
- App.tsx：未接通状态、开屏 12 小时门控
- components/Onboarding.tsx：五步文案（**步数不变**）、Key 自动校验
- components/Splash.tsx：受门控（**动画先别改**）
- components/BroadcastView.tsx：无 Key 空态
- settings.ts：加一个「上次开屏时间」

**不许动**：NMS 任何东西、黑塔币、播报生成链路。

**验收**
- [ ] 跳过引导后，主界面有常驻的「她还没接上，点这里填 Key」，点了能进设置
- [ ] 未接通时输入框是引导态，不再弹「先填 API Key」红字
- [ ] 第 2 步填完自动验一次；Key 错 / 网络不通 / 没余额三种都说人话，**且不挡着继续**
- [ ] 播报页无 Key 时说「今天还没有；接上她才会说话」
- [ ] 距上次开屏 <12 小时，或从后台切回，不播开屏
- [ ] typecheck + test + 出包

**开工提示**

    这一批做「首次流程」，见 herta-mobile/docs/开工手册.md 的 B1，和设计文档 §4。
    先读：docs/设计-手机端流程重设计-2026-11.md 的 §4、CONTEXT.md 里「未接通」那条、
    apps/phone/src/App.tsx、components/Onboarding.tsx、components/Splash.tsx、hooks/useChatTurn.ts。
    要改的只有这五个文件（外加 settings.ts 加一个「上次开屏时间」）。
    不要动 NMS、黑塔币、播报生成链路。

### B8 · 黑塔币 B（限价单 · 分享卡 · 负余额与杠杆）

**目标**：玩法变厚，但仍然只有一个 JSON 账本、一把 3 秒锁。

**先读**：设计文档 §7 的「为什么允许负数反而更简单」那段——**两道护栏缺一不可**。

**改哪**：fc/coin-api（/api/trade 支持挂单与开平空仓；state 加挂单表与空头仓位）、packages/coin（撮合纯函数 + 利息计算 + 测试向量）、components/CoinView.tsx（挂单面板、空头卡、分享卡）。

**不许动**：存储形态（仍是 OSS 单对象 + 3 秒锁）；不要引定时任务。

**验收**
- [ ] 限价单**是条件单**：价格触及即由系统按市价成交，共享挂单表可见但**没有对手方**（不要做成订单簿）
- [ ] 限价单双向挂，有效期 1h / 24h / 3d；过期作废并明说
- [ ] **日结**：每天第一次打开市场时结一次（借币利息 + 清理过期挂单）；隔几天才开就一次补齐全部天数；判据是 `lastSettleDay`
- [ ] 只在有人下单时撮合（没有定时扫盘），UI 上写清楚
- [ ] 余额可负：负数时只能平仓、不能开新仓；开仓上限 = 净资产 × 3
- [ ] 破产是用户主动「重开」：清仓 + 重置到 1000 HTC / 1 万 USDT + 破产次数 +1
- [ ] 排行榜分两个：净资产榜（负数垫底标红）+ 欠款榜
- [ ] 分享卡：纯图，能存相册、能发回对话；**按三态生成**（盈利 / 空仓 / 破产），版式见设计文档 §7 与 `docs/prototypes-2026-11/coin-share-*.png`
