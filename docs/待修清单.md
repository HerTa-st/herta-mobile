**症状**（梦源报「交互和 UI 有些问题」）：点「黑塔币」画出来的是播报页；菜单高亮跳过去了、画面没换；

**根因**：B2（`3e64d2c`，当天 08:42）把三个互斥布尔量换成页面栈，`openPage` 三个入口都走 `push`。

**修法**：加 `replacePage`（换频道语义）+ 侧栏三入口改用 `pages.replace`；
整屏页的层级由栈序给（`PAGE_Z_BASE + index`，经 `zIndex` prop 内联），CSS 里的 40/55/56 降级为兜底。
设置（z 60）仍是独立弹层，压在整屏页上面。

**验证**（0.36.0 + 本修，雷电 14，360×616）：

- 播报上开设置 → 画面是设置；关掉 → 回播报（z 60 仍然管用）。
