# Herta 手机端 v0.31.0

装她：下载 `Herta.apk`，装完第一次打开会让你填一个 DeepSeek API Key。
会话与记忆都存在本机；只有调用模型时，这一次请求的内容会发给 DeepSeek。

## 这一版（0.29 → 0.31）

**记忆换了内核**
- 从旧的 MemoryRecord 换成 NMS：ep 情景 / sem 语义 / note 语气 三层 + 带权联想图
- 存储改 Capacitor SQLite；旧记忆一次性迁移，旧库保留只读一版用于回滚
- 浅睡（零成本衰减 / 同标题去重 / 剪弱边）在启动、回前台、空闲时跑
- 深睡六阶段把对话熬成记忆，每晚有调用上限

**她会自己长语气**
- 「我说话的样子」由她自己读最近几篇记忆写出来，不再用包里那份固定指南
- 四个性子参数（说话长短 / 耐心 / 主动程度 / 称呼方式）一晚最多挪一格，最多留 5 个回滚快照

**界面按选定稿重做**
- 日常用 A（站内工作台）+ 夜间用 C（轨道控制台），左轨可收成 12px
- 输入条收口：一条胶囊 + 回形针 + 圆形发送，她说话时变「打断」
- 设置改成整屏分组

**新东西**
- 星际和平播报：每天一期，真新闻 + 一句她的评，能点回原文
- 黑塔币共享市场：填昵称进同一个市场，签到 / 买卖 / 排行榜
- 引导页加了「她怎么叫你」，名字会进人格与主动消息
- 她会按自己的行踪先开口（一天最多两次，夜里不吵）

**杂项**
- 字体改为跟随手机系统（去掉 17MB 的内置字体，包小了一圈）
- APK 按版本号出包，产物带日期
