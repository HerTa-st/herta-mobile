# Herta 手机端 v0.36.0

装她：下载 `Herta.apk`，装完第一次打开会让你填一个 DeepSeek API Key。
会话与记忆都存在本机；只有调用模型时，这一次请求的内容会发给 DeepSeek。
从 0.31 及更早升上来的，这一版把中间四批（0.32–0.35）和今天的收口一起带上了。

## 这一版（0.31 → 0.36）

**她会自己核对刚查到的东西**
- 复核这一环以前只看「候选台词 + 最近对话」，她这轮查了时间却说错，复核抓不到。
- 现在复核能看到这一轮每一条工具回执（时间、搜索结果、算出来的数），并被明确告知：
  台词跟回执对不上就是错的。没有用工具时，提示词与旧版逐字一致。

**界面收口**
- 长按会话菜单、重命名、多选条、置顶、设置页脚链接、文件列表、播报下拉、记忆删除按钮：
  这些以前是散在组件里的内联样式，现在统一成一套（菜单不再是浏览器默认灰底）。
- 触控热区补到 44×44：左轨圆点、顶栏头像 / 日夜 / 关闭、抽屉新建、设置页头按钮、
  播报 / 记忆 / 币页的返回键。视觉尺寸没动，只扩了命中区。
- 日间辅助文字对比度从 4.24 提到 5.1（`--muted` 调深一档），夜间本来全过。
  剩两处「青底透上来」的最坏合成面仍是 3.95–4.47，属于观感取舍。

**0.32–0.35 带上的东西**
- 主题包：zip 装 / 换 / 卸，只换 CSS 不动结构；`minAppVersion` 不满足会拒装。
- 关于三页：开发人员 / 赞助名单 / 已知问题；名单走远程 JSON，App 里零收款入口。
- 今日用量：判心情、工具轮、复核、重说等九条链路各自记账，本地按天清零。
- 备份与迁移：覆盖恢复、合并恢复、带上她能读的文件、恢复前自动存一份、恢复完给报告。
- 版本更新提示：只 GET 一份静态清单，拉不到就静默（你这一版才第一次真的用上）。
- 流程重设计落地：首次引导五步、页面栈 + 系统返回键、设置页瘦到十项、
  聊天页发图 / 引用 / 重新生成、记忆网络全屏、换头像换背景、开屏字符雨。

**杂项**
- 测试接线补了一个从 B8 起就漏掉的 33 项（黑塔币共享市场），全量 286 项。
- 新增两个开发工具：`tools/contrast-check.mjs`（token 对比度）、`tools/devtools-probe.mjs`（真机 DOM 探针）。
