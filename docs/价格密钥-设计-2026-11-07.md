# 价格密钥与本地行情 · 2026-11-07

**拍板**：密钥留在服务端，每天随机生成后下发；行情计算搬进手机端；共享模式的账务（钱包 / 持仓 / 挂单 / 空仓杠杆 / 签到 / 榜单）留在服务端算。
**不加降级**：服务端拿不到密钥就是开不了盘，不拿日期派生备用密钥（会和服务端算出两条线）。

## 1. 密钥与派生规则

- 切换日 `CUTOVER = "2026-11-07"`（含当天）。之前的日期走旧规则，历史价格一根都不许变。
- 每天一把密钥，16 字节随机数的 hex（32 位小写）。
- 派生字符串（coin-core 里所有 `makeRng` 的种子都从这两个函数出）：
  - 日线：`daySeed(date) = date < CUTOVER ? "HTC|daily|" + date : "HTC|daily|" + date + "|" + secret(date)`
  - 分钟路径：`planSeed(date) = date < CUTOVER ? "HTC|intraday|" + date : "HTC|intraday|" + date + "|" + secret(date)`
- `date` 一律 `YYYY-MM-DD`（上海时间）。

## 2. 服务端

### 存储
`state/coin.json` 顶层加 `seeds: { "YYYY-MM-DD": "<32 hex>" }`。缺就生成、加锁落盘，**同一日期只生成一次**。旧状态没有 `seeds` 字段按空对象处理，不要因为升级清库。

### 接口
- `GET /api/seeds?from=YYYY-MM-DD` → `{ version, cutover, seeds: { date: seed } }`
  - 返回 `[max(from, CUTOVER), 今天]` 区间内每个**交易日**的密钥；缺的当场生成并落库。
  - `from` 早于 CUTOVER 就按 CUTOVER 回；`from` 晚于今天就回空表。
  - 非交易日（周末）不用发——没有 session，客户端也画不了那天。
  - 这是唯一新增接口；CORS 头沿用现有 RESPONSE_HEADERS。
- 其余接口（`/api/daily`、`/api/state`、`/api/trade`、`/api/signin`、`/api/leaderboard`）**请求/响应形状不变**，只是内部算法改成吃密钥。`/api/daily` 的 `bars` 这一轮先留着（给对账用），下一轮再瘦身。

### 核心函数
```js
// getSecret(dateStr) -> string | null；date < CUTOVER 时可以不实现
buildDailyResponse(nowMs, getSecret)
buildPlan(dateStr, getSecret)
dailySeries(endDateStr, getSecret)
```
日线链要从 genesis 走到当天，所以 `getSecret` 会被逐日问；handler 先读一次 `seeds` 再用闭包给。

### 账务
共享模式的账务一行不动（仍用 `buildDailyResponse` 的结果），只是价格现在由密钥派生。签到价、成交价、结算价同源，不允许客户端报价参与。

## 3. 手机端（packages/coin/src/core/）

- 把 `fc/coin-api/coin-core.js` + `news-pool.js` 逐行移植成 TS，行为必须**逐位一致**（浮点比较用 `|a-b| <= 1e-9 * max(1,|b|)`）。
- 对外只暴露：`buildDailyResponse(nowMs, getSecret)`、`getSession(nowMs)`、`computeQuote`、`buildDisplay`，其余内部。
- 客户端取密钥：启动/进币页时 `GET /api/seeds?from=<cutover>`，存 localStorage（`herta.coin.seeds.v1`）；当天没拿到就显示「今天还没拿到密钥，连上就有」，不画。
- 拿到密钥后 **bars 本地算、按分钟自己长**：30s 定时器只重算重画，不重拉 bars。历史日期用缓存里的密钥复算。
- 单机模式：同样用本地算法；没密钥的日期不可看。
