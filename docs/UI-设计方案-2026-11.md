## 0. 一句话

手机端已经有桌面端那套「墨色 + 海面青 + 玻璃 + 宇宙底」的底子，缺的不是颜色，是**一套把 12 个模块组织起来的结构**。
这个方案给出三个结构完全不同的方向：A 站内工作台、B 档案室、C 轨道控制台。**最终拍板：日常用 A，夜间用 C；播报和开屏保持 A，不采用 B 的报纸 / 书封。** 这个选择已经落成原型里的 **D 选定稿**（?variant=D），并同步进手机端代码。

先看原型，再拍板：

    cd E:\deepseek工作区\HerTa\herta-mobile
    npm run prototype:ui
    # http://127.0.0.1:5199/prototype-2026-11/index.html

- 用 ?variant=A|B|C|D 换版本；D 是选定稿（A + C 夜），加 &theme=dark 看夜间
- 用 ?screen=chat|sessions|memory|coin|broadcast|settings|caps|import|backup|tools|onboarding|system 跳模块
- ← / → 换方向，M 开模块索引；手机上会铺满全屏

## 1. 口径与边界

**参考的是「桌面端 Herta」，不是 DSH 插件。** 桌面端的界面源码在 Herta-src/packages/gui，主界面由 reference-ux.css 描述：海面青宇宙底、半透明白玻璃、#111417 墨色、18px 卡面、Inter + 系统中文、等宽字体承担读数。手机端 styles.css 开头已经抄了同一套 token，所以这次不是「从零做桌面风」，是**把这套语言推到每一个模块，并决定谁该重、谁该轻**。

**只谈 UI。** 不改 agent loop、协议、NMS 数据模型、黑塔币算法、播报生成链路。原型里的数字全是手写 mock，按钮不写库、不联网、不调模型。

**不改现有代码。** 原型是 design/ 下的静态文件，不参与 vite build、不进 APK；npm 只加了一条 prototype:ui 脚本。正式落地时按第 10 节的顺序拆 App.tsx，而不是把原型代码搬进去。

## 2. 桌面端到底给了什么

从 reference-ux.css 与实际界面里能复用的，只有这几件事：

| 维度 | 桌面端的做法 | 手机端怎么接 |
|---|---|---|
| 底 | 青绿蓝的宇宙渐变 + 一层 bloom，不是纯白 | 保留；它让玻璃有东西可透 |
| 壳 | rgba(250,252,253,.88) + blur(25px) saturate(145%) | 保留，但只给「容器」，不给每一行 |
| 墨 | #111417 / #3B4350 / #717984 / #8B90A0 四级 | 正文与元数据用同一套阶梯 |
| 强调 | #2F7D92（青）与 #2563EB（蓝），低饱和 | 青=「她/信号」，蓝=「链接/系统」，不混用 |
| 卡面 | 18px 圆角、1px 半透明描边、极轻投影、内高光 | 卡片 18，控件 9–12，胶囊 999 |
| 字 | Inter + 系统中文；读数用等宽 | 正文 15/1.7，元数据 10–11 等宽 |
| 动效 | cubic-bezier(.2,.85,.2,1)，800ms 的 morph 是签名 | 手机只保留 140–260ms 的进出，不搬 morph |
| 气质 | 不装饰、不渐变按钮、玻璃只当容器 | 不要给每个模块换一套皮肤 |

**桌面端没有回答的问题：** 手机只有 390 宽，左栏/右栏/工作区三栏放不下；播报、黑塔币、记忆网络这些「桌面上的第二栏」在手机上必须是独立页面。三个方向就是三种回答。

### 3.2 不在「页面」里、但必须被设计的系统

这些没有独立入口，却决定了界面像不像她：

- **人格（Bio / 废案 / 处境 / 输出契约）**：不可见，但决定语气；设置里只暴露「模型/省 token」这种可解释项。
- **叙述（想 / 说）**：想是页边批注，说是正文；缺闭合标签时宁可空着。
- **心情 + 情绪惯性**：八档，平静档随语境微调；界面只显示一枚小状态，不做仪表盘。
- **行踪**：按钟点算；显示在顶栏第二行（「凌晨 02:14 · 实验舱」）。
- **做梦 / 深睡**：抽屉里的「让她做梦」+ NMS 的浅睡/深睡；夜里 cap 8 次。
- **语气笔记**：她自己写的「我说话的样子」，记忆页里可读，只读。
- **主动消息 / 提醒 / 播报提示**：落在会话里，不进独立通知中心。
- **表情包 / 看图 / 文件库**：聊天输入区与设置里的文件库，工具记录里留痕。
- **TTS / 语音**：气泡上的「▶ 念」，不是一级模块。
- **无障碍 / 相册 / 相机 / 定位 / 日历 / 打开应用 / 分享**：能力页里的权限矩阵。

## 4. 三个方向

### A · 站内工作台（Station Desk）

**一句话：** 把桌面端的玻璃工作区压进手机，左轨常驻，模块是同一层工作区的切换。

- **结构**：58px 左轨（她的标记 / 新建 / 对话 / 记忆 / 黑塔币 / 播报 / 设置 / 更多）+ 顶栏（会话、标题、行踪、心情、头像）+ 内容层；非一级页面（设置、能力、导入、备份、工具、开屏、设计系统）通过会话页的「全部模块」或设置里的入口进入。
- **对话**：白玻璃气泡；想=青色左边线的等宽小块；动作=括号里的斜体；说=正文；底部「念 / 用量 / 时间」。工具旁白是缩进的一行灰字。表情包是一张贴纸卡。
- **记忆**：网络图置顶（188px），下面四格统计、浅睡/深睡、最近被想起列表（权重条）、语气笔记。
- **黑塔币**：价格 + 分钟 K + 钱包/签到两卡 + 共享市场排行。
- **播报**：期头卡 + 头条卡（来源/标题/摘要/评）+ 其余条目 + 关注标签 + 历史期。
- **设置**：档案卡 + 三个快捷入口 + 连接/她/模块/数据四组；开关是 iOS 风格的胶囊。
- **代价**：左轨永久吃掉 58px；390 宽下正文区只剩 332，长标题会挤。
- **适合**：想保留「桌面端的工作台感」，把手机当第二现场。

### B · 档案室（The Archive）

**一句话：** 把 App 做成一册她的档案：纸面、卷目、图版、印章。导航不是 tab，是翻页和索引。

- **结构**：没有常驻导航。顶部是 HERTA 刊头 + 「索引」；底部是页码 + 左右翻页；「索引」拉出全屏卷目（12 章，两列）。
- **对话**：通信记录体。左边 38px 页边栏写「你/她 + 时间」，正文是衬线；想=米色批注框，动作=句后斜体；工具旁白=居中的「查了：…」；表情包=贴入的纸条。
- **记忆**：图版 I（网络）+ 四格数字 + 浅睡/深睡 + 目录（01–06）+ 语气笔记（虚线卡片）。
- **黑塔币**：行情公报。大号等宽价格、图版 II（K 线）、持仓/签到两栏表、共享市场表；朱红「涨」印章只在这一页出现。
- **播报**：真正的报纸头版。刊名、期号、头条、引文「评」、其余短讯、关注标签、历史期。
- **设置**：登记簿。每行「标签 …… 值」，开关是 ☑/□；没有卡片，只有线和点。
- **代价**：密度低、扫读慢；高频操作（切会话、看行情）要多翻一页；索引是唯一快速通道。
- **适合**：想让她「像一件被保存下来的东西」，私密、慢、有手感；播报页尤其适合这套语言。

### C · 轨道控制台（Orbit Console）

**一句话：** 把她放进空间站终端：深空底、青色信号、等宽读数。对话是频道，记忆是核心，黑塔币是交易台。

- **结构**：顶部 29px 状态条（HERTA OS / 时间 / LOCAL / 电量）+ 48px 系统坞（每个模块一个 LED）+ 主区 + 底部命令条（⌘K）。
- **对话**：不是气泡，是频道转录。每条有 YOU/HERTA 元数据；想是「// THOUGHT」注释行，动作是 [ 方括号 ]；底部输入是「› TRANSMIT TO HERTA…」+ SEND。
- **记忆**：核心面板。NETWORK/LOD 大图 + 四角准星 + 四格读数 + LIGHT/DEEP SLEEP + 节点列表 + VOICE 只读区。
- **黑塔币**：交易台。价格、K 线、BUY/SELL 报价、下单按钮、POSITION、签到条、LEADERBOARD。
- **播报**：传输记录。TRANSMISSION 017、来源、评（COMMENT）、其余传输、TAGS、历史。
- **设置**：开关台。每个分组是一块面板，开关是带 LED 的拨杆；顶部四个快捷读数（CAPS/TOOLS/SNAP/IMPORT）。
- **代价**：暗色 + 高密度，白天户外可读性差；信息层级靠颜色和等宽，对普通用户有门槛。
- **适合**：想强调「她是一个系统，不只是聊天对象」，夜间使用最多；也适合做 C 的暗色皮肤，而不是全量替换。

### 4.1 横向对比

| 维度 | A 站内工作台 | B 档案室 | C 轨道控制台 |
|---|---|---|---|
| 首页 | 对话 | 通信记录（也是对话） | 通信频道 |
| 导航 | 左轨常驻 | 翻页 + 索引 | 系统坞 + LED |
| 一级模块数 | 5 个图标 + 更多 | 12 章 | 5 个坞位 + 更多 |
| 信息密度 | 高 | 低 | 最高 |
| 对话气质 | 白玻璃气泡 | 衬线记录 | 终端转录 |
| 记忆页 | 图 + 列表 | 图版 + 目录 | HUD + 事件流 |
| 播报页 | 信息流 | 报纸头版 | 传输记录 |
| 最像桌面端 | 是（直接压缩） | 像桌面的「纸面模式」 | 像桌面的暗色模式 |
| 主要风险 | 左轨吃宽度 | 高频操作慢 | 白天可读性 / 电量 |
| 适合场景 | 日常主力 | 播报 / 开屏 / 收藏 | 夜间 / 极客 |

## 6. 拍板：A 的日常 + C 的夜

**主结构选 A。** 理由不是「像桌面」，而是使用频率：手机端 80% 的时间在对话与会话之间，A 把这两件事放在第一层；记忆/播报/黑塔币是「偶尔打开」，左轨一次可达；设置类低频页通过会话页的模块格兜底。B 的翻页在低频页很好，但在高频页会多一次操作；C 的暗色适合夜里，但白天对比度和电量都不划算。

**具体选择：**

1. **A 的壳**：58px 左轨、玻璃顶栏、宇宙底；左轨可收成 12px 的「把手」，点一下展开（解决吃宽度）。
2. **A 的对话**：白玻璃气泡 + 独立的「想」块；想块沿用 A 的浅青左边线，不搬 C 的终端排版。
3. **A 的播报**：保持 A 的信息流（期头卡 + 头条 + 条目 + 标签），不搬 B 的报纸头版。播报是低频页，但已有 A 的卡片结构，用户不需要再学一种版面。
4. **A 的开屏**：保持 A 的玻璃封面 + ASCII 半调，不搬 B 的书封。
5. **C 的夜间**：不换布局，只换 token。深空底、青色信号、等宽读数沿用 A 的骨架；输入、图表、空态都要一起换。
6. **不混的**：B 的报纸 / 书封不进入正式版；C 的坞不出现；A 的左轨只有一份。

**一句话验收：** 白天的 A 和夜里的 C 应该像同一个产品的两个时刻，而不是两个 App；播报和开屏必须仍然是 A 的那一页。

### 6.1 已落成 D 选定稿

原型里的 D 已经按拍板改成「A 的日常 + C 的夜」，可以直接验收：

- **壳**：A 的左轨 / 顶栏 / 对话 / 记忆 / 黑塔币 / 设置；左轨右缘有一个把手，可收成 12px（实测正文区多出 46px：桌面设备框 314→360，手机 332→378）。
- **播报 / 开屏**：回到 A 的信息流与玻璃封面；B 的报纸 / 书封只留在 B 方向里作参考。
- **夜**：顶栏的「夜 / 日」键切换；只换 token、不换布局；URL 会带 theme=dark，刷新保持。
- **没混的**：B 的衬线没有扩散到对话/设置；C 的坞没有出现；A 的左轨仍然只有一份。

验收时先看 D 的对话 → 播报 → 开屏 → 再按「夜」，如果这四步像同一个产品的连续动作，这个选择就成立。

## 7. 设计 token

### 7.1 颜色

| token | Light（A/B） | Dark（C / 夜间） | Paper（B） |
|---|---|---|---|
| 底 | 宇宙青渐变 #25B7EE→#8FECE7→#14A5E2 | #061018 → #0D2233 | #F6F3EC |
| 墨 | #111417 | #E6F7FC | #16130F |
| 二级墨 | #3B4350 | #B6D0DF | #3D372E |
| 弱化 | #717984 | #8FADC2 | #6F675C |
| 最弱 | #8B90A0 | #6A8AA0 | #9A9184 |
| 线 | rgba(17,20,23,.09) | rgba(110,231,255,.16) | rgba(22,19,15,.16) |
| 强调 | #2F7D92 | #6EE7FF | #8A3A2E（印章） |
| 链接/系统 | #2563EB | #7DFFC4 | #2F6B66 |
| 涨 | #D96A7A | #FF6B7D | #8A3A2E |
| 跌 | #4F9D8A | #57E3B2 | #2F6B66 |

原则：青=她/信号，蓝=链接/系统，朱红只做印章与「评」；涨跌沿用用户熟悉的红涨绿跌，不为了好看改。

### 7.2 字阶

| 角色 | 字号/行高 | 字重 | 用在哪 |
|---|---|---|---|
| Display | 25 / 1.2 | 620 | 开屏、设计系统标题 |
| H1 | 18–20 / 1.3 | 620 | 页面标题 |
| H2 | 15–16 / 1.4 | 600 | 卡片标题、头条 |
| Body | 14–15 / 1.7 | 400 | 对话正文、说明 |
| Body small | 12–13 / 1.6 | 400 | 列表副文、摘要 |
| Meta | 10–11 / 1.5 等宽 | 400–500 | 时间、权重、token、状态 |
| Micro | 9–10 等宽 | 400 | 只在低频标签；正式版不建议再小 |

**和原型的差异：** 原型为了在 390×844 里塞下所有状态，把 Meta 压到 6.5–9px；正式实现请用上表的 10–11px，宁可多滚一屏。原型 README 也写了这条。

中文用系统字体（PingFang SC / Microsoft YaHei / Noto Sans SC），拉丁用 Inter；B 原型里的标题/正文用 Songti SC / Noto Serif SC，只在那个方向里作参考。

### 7.3 间距、半径、投影

- 4px 基准：4 / 8 / 12 / 16 / 20 / 24；页面左右 12–16，卡片内 12–14。
- 圆角：卡片 18，面板 12，控件 9，胶囊 999；B 原型里的纸面卡 0–2，C 的面板 10–11。
- 投影：Light 用 0 12px 32px rgba(32,45,58,.045) + 内高光；Dark 用内描边 + 极弱外发光；B 不用投影，用 1px 线和纸纹。
- 触摸目标最小 44×44；原型里 30px 的图标按钮在正式版要加透明热区。

### 7.4 动效

- 页面进出 180–260ms，cubic-bezier(.2,.85,.2,1)；不做桌面端 800ms 的 morph。
- 流式文字不做逐字打字机，直接追加；想/说切换只做透明度。
- 网络图/ K 线的首次绘制 300ms 内完成；切 tab 不重排整页。
- 尊重 prefers-reduced-motion：关掉脉冲、星星、呼吸光。

### 7.5 图标与图像

- 线稿 1.7px、圆头圆角，24 视框；与桌面端同一套笔画。
- 她的头像用近景侧脸；聊天里 28–30px，开屏 104–116px，封面可灰度化。
- 表情包是「她挑的」：贴纸卡展示，不放大成图库。

## 8. 模块规格（正式实现要补的）

### 8.1 对话

**结构：** 顶部上下文条（记忆 3 篇 · 复核开 · 省 token 关）→ 日期线 → 消息流 → 输入区。
**她的一条消息：** 头像 + 想块（可选）+ 动作（可选）+ 说 + 底部（念 / 用量 / 时间）。
**你的一条：** 右对齐灰气泡 + 时间；图片/文件在气泡内。
**状态：**

- 流式中：气泡内追加，发送钮变「打断」。
- 只有想、没有说：这一轮留空，不把想当台词；UI 显示一行「她没说出来」。
- 工具轮：聊天里一行灰字「（上网查了：…）」，完整参数在工具记录。
- 撤回上一轮：胶囊上方一行小字，点了才真撤。
- 错误：不弹 toast，落在输入区上方的一行；保留可重试。
- 省 token：上下文条显示「省 token 开」，不隐藏，避免用户以为她变笨。

**规则：** 想永远不念；动作永远不念；用量徽章点开看输入/输出/缓存命中/调用次数；长图按宽度切段，气泡只拿第一片当缩略图。

### 8.2 会话与检索

- 顶部搜索（记忆 + 会话），下面分段「全部/最近/导入」。
- 会话行：标题、来源（本机/导入）、块数、时间；当前会话有青色点。
- 搜到记忆：点开记忆详情；搜到会话：跳到那一块。
- 底部「全部模块」网格：12 个入口，低频页的兜底。
- 删除会话要二次确认；导入的会话标「导入」，不自动进记忆。

### 8.3 记忆 NMS

- 三个 tab：网络 / 列表 / 设置；默认网络。
- 网络：节点大小=有效权重，颜色=ep/sem/note，边=关联；点节点看全文；顶部四格（活跃/压缩/平均权重/上次浅睡）。
- 列表：按权重排，每行 tier 标签 + 标题 + gist + 权重条；搜索标题/要点。
- 设置：深睡开关、cap、浅睡时机、是否显示网络；与设置页的「她」组不重复。
- 动作：浅睡（去重/衰减/剪边）、深睡（六阶段 LLM，cap 8/晚）；按钮要显示进度与失败原因。
- 语气笔记：只读，标题写「她写字的样子（N 篇记忆之后）」。
- 空态：还没有记忆时，不显示空图，显示一句「睡一觉之后，新的情景会出现在这里」。

### 8.4 黑塔币

- 顶部：币名/交易对/状态（交易中/盘前/午休/已收盘/休市）+ 最新价 + 涨跌 + OHLC + 量。
- 图：分钟 K 按已揭示根数铺满，成交量副图，MA5，均价线，十字光标；收盘后显示全天。
- 钱包：持有/成本/浮盈/收益率；签到：连签、下一档奖励、签到按钮（以 serverTime 为准）。
- 共享市场：昵称/QQ 号、在线人数、排行、净买入推价；留空是单机模式。
- 未配置接口：明确说「未配置接口」，不要假装行情是 0。
- 文案：v1 不接她、不做交易；这句要出现在页面底部，不藏在设置里。

### 8.5 星际和平播报

- 期头：第 N 期、日期、星期、「空间站黑塔转播」、已生成条数。
- 头条：来源/域名/阅读时长、标题、摘要、「评」引文、读原文/和她聊这条。
- 其余：来源、标题、摘要、评、标签；彩蛋条目要有明显的虚构标记（虚线条/「彩蛋」标签）。
- 关注标签：显式清单，可加/删；NMS 只建议，不自动改。
- 历史：往期列表，点开重读。
- 空/失败：今天还没生成时给「今天的还没到」+ 重试；不要显示上期冒充今天。

### 8.6 设置

四组：

1. **连接**：API Key（密码框，只存本机）、Base URL、模型、省 token。
2. **她**：判心情、复核、自动做梦、深睡、主动想起你。
3. **模块**：播报时间、黑塔币提醒、读屏/无障碍、相册。
4. **数据**：备份与迁移、工具调用记录、文件库、表情包。

规则：一行一个可解释项；开关旁写代价（例如省 token「不判心情 / 不复核」）；API Key 永不进备份；所有设置本机，不出现「同步到云端」。

### 8.7 她能做什么

权限矩阵：通知、相机、相册、定位、日历、打开应用、分享、主动想起、读屏/无障碍。
每行：名称、用途、边界、状态（已开/询问/关闭）。无障碍与相册单独标注「高权限，默认关闭」；她只能说「我需要」，不能自己开。

### 8.8 导入 DeepSeek

- 主路径：分享链接 → 取 → 预览条数 → 归档；公开接口，不需要登录。
- 备选：油猴 JSON / 选文件。
- 导入后：原文按块归档，标「导入」；不自动进记忆；打开会话点「让她做梦」才消化。
- 文案要说明链接用完可在 DeepSeek 删除；导入不是「同步」，是「归档」。

### 8.9 备份与迁移

- 清单：会话、记忆、文件库、钱包、表情、设置；API Key 不打包。
- 体积与上次打包时间；打包/恢复/只导出会话。
- 恢复时本机已有钱包则不覆盖；失败要给具体原因。

### 8.10 工具调用记录

- 时间、工具名、参数摘要、结果、耗时、成功/被拒。
- 失败也留痕；被系统拒绝的那次比省略更诚实。
- 筛选：全部/失败/写类；不把工具旁白刷回聊天页。

### 8.11 开屏与引导

- ASCII 半调：她由几千个字符逐帧亮起，白底，播完淡出；系统闪屏压成同色，避免多一页。
- 首次引导：她在这里 + 两个动作（开始 / 从 DeepSeek 导入）；不塞权限申请。
- 日常启动只播 ASCII；B 的书封只留在原型，不进入正式版。

### 8.12 设计系统页

只在开发/预览里出现：颜色、字阶、半径、部件、状态。正式包不打包。原型里的这一页是给评审看的，不是用户功能。

### 8.13 环境系统

- **心情/行踪**：顶栏一行小字，不做仪表盘；心情变化不弹提示。
- **做梦/深睡**：抽屉/NMS 里手动触发；自动时只在设置里说「空闲且攒够材料时」。
- **语气笔记**：记忆页只读；不提供编辑，避免用户替她写。
- **主动消息/提醒**：落在会话里；提醒卡可点「知道了/稍后」；不建独立消息中心。
- **表情/看图/文件**：输入区回形针拆「拍照/选文件」；文件库进设置；工具记录留痕。
- **TTS**：气泡上的「念」，失败只影响这一句，不挡文字。

## 9. 交互与导航

- **首页 = 对话**：打开就是她，不是仪表盘；A 的左轨是唯一常驻导航。
- **两级可达**：12 个模块都能从首页 ≤2 次点击到达（A：左轨或会话页模块格；B：索引；C：坞 + 矩阵）。
- **返回**：全屏页要有明确的关闭/返回；Android 返回键先关覆盖层再退页；不要用「再按一次退出」。
- **覆盖层变页面**：现在的 Settings/Backup/ToolLog 是 sheet；正式版建议改成整页（保留 sheet 动效），这样返回栈与深链都简单。
- **空/加载/错误**：每个模块都要有；错误落在内容区，不用系统 toast 代替。
- **手势**：左轨可收；长按消息复制；图片点开全屏；不做隐藏手势（侧滑返回除外）。
- **无障碍**：焦点顺序按视觉顺序；图标按钮有 aria-label；开关有 role=switch；对比度正文 ≥4.5:1；支持系统字号放大。

## 10. 迁移路径

现状：App.tsx 69.5 KB、styles.css 63 KB，没有 router，页面用布尔状态叠覆盖层。建议按下面顺序拆，不要一次重写：

**P0 · 壳与 token（1–2 天）**
- 抽 ui/tokens.css（颜色/字阶/半径/间距/动效），把 styles.css 开头的变量迁进去。
- 抽 Shell / Rail / TopBar / Page 四个组件；App.tsx 只保留回合编排。
- 建立 screen registry（12 个 key），先全部指向现有组件，保证行为不变。

**P1 · 对话（2–3 天）**
- 气泡拆成 MessageBubble / ThoughtBlock / ActionLine / UsageChip / ToolNote / StickerCard。
- 输入区拆 Composer；长图/文件/表情走同一条附件管线。
- 先上 A 的视觉，C 的想注释作为可选 token。

**P2 · 会话 + 记忆（3–4 天）**
- Drawer 拆成 SessionsPage（全屏）+ ModuleGrid。
- NmsScreen 换成 token 化样式；网络图全屏时用 C 的准星/图例；列表用 A 的权重条。

**P3 · 播报 + 黑塔币（3–4 天）**
- 播报保持 A 的信息流；不引入 B 的报纸版面，也不改生成链路。
- 黑塔币沿用现有 CoinView 逻辑，换 A 的卡面；K 线保持现有 chart.ts。

**P4 · 设置/能力/导入/备份/工具（2–3 天）**
- sheet → page；设置四组；能力矩阵用 A 的卡 / 行；导入/备份/工具用 A 的卡。

**P5 · 开屏 + 验收（2 天）**
- ASCII 半调保留；B 的书封不进入正式版；360/390/412 三档宽度、暗色、reduced motion、TalkBack 走一遍。

**风险：**
- App.tsx 是单文件巨石，边拆边跑 typecheck + 现有测试；不要改回合编排的逻辑。
- 没有 router，返回栈要自己建；先做「页面栈数组」，再做手势。
- 玻璃 + backdrop-filter 在低端机可能掉帧；给「省电模式」降级为不透明卡面。
- 网络图 canvas 在 390 宽下的标签碰撞；原型已把标签收到 3 个，正式版要做避让。
- 6–9px 的元数据不能进正式版；字号提升后布局会变，需要在 P1 就定稿。
